OOP CONCEPTS:
  1. Encapsulation: Private fields, getters, setters in all entity classes
  2. Inheritance: Admin extends User (abstract parent)
  3. Polymorphism: displayRole() overridden in Admin
  4. Abstraction: HotelService abstract class with concrete service implementations
  5. Association: Entity relationships with @OneToMany, @ManyToOne, @OneToOne
